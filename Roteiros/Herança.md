# Herança 


### classes se realcionam e herança é um tipo de relacionamento entre elas
 |_favorece reutilização de classe
  

 - Observar caracteristicas e comportamentos semelhantes entre as classes
    
        Exemplo: 
        Paciente   Médico
        -Nome      -Nome
        -Cpf           -Cpf
 
 - Herança é o relaciomento generalização/especialização

## Herança Simples ou Múltipla 

Quando a subclasse herda apenas de uma classe, ela é herança simples, já a herança múltipla herda de duas classes diferentes

#### Obs: Java não trabalha com Herança Múltipla


##### public Paciente *extends* Pessoa {...
    - Isso quer dizer que a classe Pessoa vai herdar a classe Paciente
