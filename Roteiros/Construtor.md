# Construtor

### Método Especial
  - Não tem tipo de retorno
  - Mesmo nome da classe
## Função
 - Definir espaço do objeto / inicializar atributos

### Tipos de Construtores 
- Construtor padrão
- Construtor parametrizado


### Exemplo 

Inicalização de uma instância padrão: Pessoa p = new Pessoa(); 
--> Utilizando o construtor para inicializar a classe ficará assim: Pessoa(parametros);
